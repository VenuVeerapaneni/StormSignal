# Submission description

**Project:** StormSignal  
**Problem statement:** TravelTech — Real-Time Crisis Communication for Tourists During Extreme Weather Events

StormSignal is a multilingual, mobile-first prototype that helps visitors understand official Chennai district weather warnings. It displays the latest published warning snapshot from the India Meteorological Department (IMD), preserves the exact source wording and update date, and pairs it with practical safety guidance in English, Tamil, and Hindi. A scheduled GitHub Actions refresh checks the public IMD district-warning page every 30 minutes. The app clearly identifies stale or unavailable data and links to official Chennai help contacts.

The public demo is [StormSignal on GitHub Pages](https://venuveerapaneni.github.io/StormSignal/), and the source is in the [public GitHub repository](https://github.com/VenuVeerapaneni/StormSignal). The prototype uses static HTML, CSS, and JavaScript, with a small Python standard-library updater.

StormSignal provides district-level forecast information, not street-level flood conditions, safe routes, or confirmed shelter availability. It is not an emergency or rescue service; travelers should follow current local authority instructions.
